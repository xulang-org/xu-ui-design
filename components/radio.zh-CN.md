# 单选组与选项 Radio

互斥单项选择组与可选中选项行，使用明确的分组语义包装关联选项。以下为组件设计与交互契约；展厅中的浏览器实现与原生边界分别说明。

## 结构

- 分组容器（`<fieldset>` 与可见 `<legend>` 标题）
- 选项行：单选指示器、主标题与可选辅助说明
- 选中边界提示与实时选择状态反馈

## 状态矩阵

| 状态 | 必须满足 |
| --- | --- |
| 未选中 | 默认表面背景配浅边框与空心单选圆钮 |
| 选中态 | 品牌主色单选填充配高亮边框，同时保持正文高对比度 |
| 悬停态 | 启用状态下提供轻量背景区分 |
| 聚焦态 | 当前聚焦单选控件展示清晰 2 px 焦点外框 |
| 禁用态 | 原生 `disabled` 并附带不可用原因，方向键导航自动跳过 |

## 键盘行为

- Tab 进入或离开单选组并落位在当前选中项上。
- 上下／左右方向键在同组启用选项间移动并切换选中值。
- 空格（Space）选定当前焦点项，绝不跨组串联。

## Token 与尺寸

使用 `--xu-surface`、`--xu-border`、`--xu-brand`、`--xu-text`、`--xu-muted`、`--xu-focus` 与 `--xu-target-min`。选项行在 Web 上不少于 `44 px` 高度，移动端 `#ui/phone` 不少于 `48 dp`。

## 原生映射

对应 `widgets.Radio` / `widgets.RadioGroup` / `widgets.radio_group` 与 `#ui/phone` 的 `phone.radio_row` / `phone.check_row` / `phone.segmented`。

## 验收

- 可在示例中切换互斥策略项、对比辅助说明与禁用前提项并观察状态同步。
- `320 px` 视口下长选项标题与辅助说明自然折行，无水平溢出。
- 必须用 `fieldset` + `legend` 绑定同组单选项，禁止仅靠位置相邻表示分组。
- 浏览器回归覆盖键盘方向键切换、实时结果播报及双主题 WCAG 2.2 AA 合规。
