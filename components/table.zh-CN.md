# 表格与分页

排序、分页、虚拟化长列表、单元格编辑、列配置与操作名称。以下是组件的设计与交互契约，Web 参考实现与原生能力边界分别说明。

## 结构

- 带有排序、筛选和列菜单控制项的语义表头
- 具备行缓存复用机制的虚拟滚动数据视口
- 左右两侧固定/冻结列区域
- 单元格行内编辑器（文本、数字、下拉选择、日期）与校验提示弹层
- 行多选指示器与批量操作工具栏
- 结果计数与分页导航控制区

## 状态矩阵

| 状态 | 必须满足 |
| --- | --- |
| 带有数据 | 完整的表头到单元格关联，具备 aria-rowindex 与 aria-colindex |
| 已排序 | 排序列标头上使用 aria-sort 明确表达升序或降序 |
| 虚拟滚动中 | 视口仅渲染可见行加缓冲行；总高度与真实滚动条比例完全对应 |
| 单元格编辑中 | 行内输入框获得焦点；Enter/Tab 提交修改，Esc 还原初始值 |
| 冻结列 | 固定列在水平滚动时保持吸附，边缘带有阴影或边框分割线 |
| 多行选中 | 多选复选框准确反映选中数与半选状态；批量操作栏激活 |
| 首页 / 末页 | 上一页 / 下一页原生禁用 |
| 空结果 | 保留筛选条件；提供明确的清除入口 |
| 已更新 | 结果条数变化与数据修改结果在 role=status 区域播报 |
| 窄屏幕 | 表格容器内部横向滚动；页面整体不产生横向溢出 |

## 键盘行为

- Tab 键可依次到达排序按钮、交互单元格操作项和分页按钮；Enter / Space 执行动作。
- 在可编辑网格模式下，方向键在单元格之间平滑移动；Enter 或 F2 进入编辑模式；Escape 取消编辑。
- 在编辑模式下，Tab 提交当前单元格修改，并将焦点移至阅读顺序中的下一个可编辑单元格。
- 在行复选框或选择列获得焦点时，按 Space 键切换该行的选中状态。
- 不可将只读表格伪装成必须二维按键漫游的复杂 grid。

## Token 与尺寸

使用 --xu-text、--xu-muted、--xu-brand、--xu-focus、--xu-surface、--xu-canvas 和 --xu-control-border。默认行高 40 px；排序和动作按钮的触控目标至少 44 px。组件必须适配暗色和亮色，并尊重用户根字号与减少动效偏好。

## 原生映射

widgets.Table / widgets.table；虚拟化行缓存复用与 draw.TextLayout 槽位共享、原生 TextInput 行内单元格浮层、列宽与拖拽重排追踪，以及平台 UIA / NSAccessibility 表格和网格模式映射。

## 验收

- 默认、虚拟化滚动、单元格编辑、排序、多选和禁用状态均可在对应效果中操作或对照。
- 超过 10,000 行的大数据量下虚拟滚动保持稳定 60fps 帧率，无内存泄漏。
- 单元格行内编辑与系统 IME 深度整合，提交合法文本并准确展示本地化校验错误。
- 320 px 下没有页面级横向溢出，冻结列在窄视口下支持平滑解冻或自适应换行。
- 使用原生语义或完整 ARIA 表格/网格关系；单元格修改结果通过 role="status" 播报。
- 浏览器回归覆盖虚拟滚动、单元格编辑提交与取消、列重排；屏幕阅读器语音真实验收另行记录，不以自动扫描代替。
