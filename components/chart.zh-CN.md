# 画布与图表

2D 画布图元、序列显隐、键盘数据点检视与图表类型切换。以下是组件的设计与交互契约，Web 参考实现与原生能力边界分别说明。

## 结构

- 图表类型切换栏（折线、面积、柱状、环形）
- 可切换显隐的序列图例按钮（带 `aria-pressed` 与色标）
- 2D 绘图舞台（坐标网格、序列图形、十字准星与空状态反馈）
- 可聚焦的数据点检视按钮与实时 `role="status"` 数值读数
- `#ui/draw` 核心图元对照卡片（矢量路径、裁剪图层、线性渐变）

## 状态矩阵

| 状态 | 必须满足 |
| --- | --- |
| 默认 | 至少一条可见序列，当前激活数据点与状态读数同步 |
| 图例切换 | 点击图例切换 `aria-pressed`，隐藏序列降低透明度并从绘图区移除 |
| 全部隐藏／空状态 | 全部序列关闭时显示明确空状态说明与一键恢复按钮 |
| 类型切换 | 在折线、面积、柱状与环形图之间切换时保留当前选中数据点周期 |
| 聚焦／检视 | 十字准星与强调环跟随激活数据点，状态栏播报完整指标与单位 |
| 窄屏 | 320 px 下工具栏自动换行，画布等比缩放且不产生页面级横向滚动 |

## 键盘行为

- 数据点检视条支持 `ArrowLeft` / `ArrowRight` 循环切换相邻周期，`Home` / `End` 跳至首尾数据点。
- 图表类型与图例按钮均可通过 `Tab` 聚焦，并用 `Enter` 或 `Space` 切换状态。

## Token 与尺寸

使用 `--xu-chart-1` 至 `--xu-chart-8` 双主题序列色板，配合 `--xu-surface`、`--xu-elevated`、`--xu-border`、`--xu-text`、`--xu-muted` 与 `--xu-focus`。交互按钮高度与触摸目标至少 44 px；减少动态效果开启时直接切换图形，不播放路径插值动画。

## 原生映射

`draw.Frame`、`draw.Path`、`draw.Surface`、`draw.DisplayList` 与 `widgets.Chart` 由 `#ui/draw` 和 `#ui/widgets` 提供；原生宿主通过 `XDF1` 二进制帧协议校验命令上限、状态栈平衡与变换矩阵可逆性，颜色契约可通过 `xuui_tokens.chart_appearance(dark)` 与 `xuui_tokens.prepare_frame($&frame, dark)` 接入。

## 验收

- 默认、聚焦、图例隐藏、空状态恢复与四种图表类型均可在对应效果中操作或对照。
- 320 px 下没有页面级横向溢出，长名称和空数据保留含义。
- 使用原生语义或完整 ARIA 关系；所有序列信息同时具备文本读数，不单靠颜色区分。
- 浏览器回归覆盖图表类型切换、图例全部关闭后的空状态恢复与键盘方向键检视。
