# 拖拽工作区

面板停靠、标签拖动重排、分割容器与无障碍工作区布局。以下是组件的设计与交互契约，Web 参考实现与原生能力边界分别说明。

## 结构

- 工作区停靠根容器
- 带有抓取手柄和头部标签的可停靠面板
- 放置区指示线与高亮图层（左/右/上/下切分，中心合并为标签）
- 浮动拖拽半透明预览镜像
- 布局预设与重置控制项

## 状态矩阵

| 状态 | 必须满足 |
| --- | --- |
| 静止 | 所有已停靠面板自适应视口；切分比例完整保持 |
| 面板拖拽中 | 半透明预览镜像跟随指针移动；可放置区域实时激活 |
| 放置候选激活 | 放置区指示高亮目标边缘（线高亮或半透明背景覆盖） |
| 放置完成 / 稳定 | 布局树即时更新；键盘焦点随之转移至新停靠面板 |
| 取消拖拽 | Esc 键或指针丢失还原前一布局，无闪烁或错位 |
| 最小化 / 最大化 | 单个面板最大化填满容器；退出时完全还原各面板结构 |

## 键盘行为

| 快捷键 | 动作 |
| --- | --- |
| Alt+M / Option+M | 在聚焦的面板头部进入键盘移动模式 |
| 方向键（移动模式下） | 选择目标停靠方向（左侧、右侧、上方、下方、居中为标签） |
| Enter / Space | 确认移动并将面板停靠至选中目标区域 |
| Escape | 取消当前拖拽或移动模式，还原初始位置 |
| Ctrl+Tab / Ctrl+Shift+Tab | 在工作区各面板之间轮转切换焦点 |

## Token 与尺寸

使用 --xu-surface、--xu-canvas、--xu-control-border、--xu-brand、--xu-focus 与 --xu-muted。面板标题栏高度至少 36 px；拖拽手柄触控目标至少 44 px。放置目标指示线使用 2 px 品牌色高亮。组件必须适配暗色和亮色，并尊重减少动效偏好。

## 原生映射

widgets.Workspace / widgets.SplitView；原生多画布宿主停靠容器，桥接 Win32 OLE / macOS Cocoa 系统级拖放协议与目标注册。

## 验收

- 默认布局、活动拖拽、放置区高亮、最大化与还原状态均可操作或对照。
- 提供完整键盘替代方案，无需指针拖拽即可完成面板停靠与重排（满足 WCAG 2.5.7）。
- 在 320 px 或窄视口下，工作区平滑降级为单列纵向布局或纯标签页视图。
- 屏幕阅读器通过 live region 实时播报面板移动结果、停靠方向与布局配置变更。
- 自动化测试覆盖布局树序列化、重排与拖拽取消；实体指针与触控手势在目标硬件上验证。
