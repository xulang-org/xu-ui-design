# 模态对话框 Dialog

带有遮罩幕布、键盘焦点锁定、明确确认选项与安全焦点恢复机制的阻断式决策浮层。以下为组件设计与交互契约；展厅中的浏览器实现与原生边界分别说明。

## 结构

- 弱化底层内容并阻断误触的遮罩层（`--xu-overlay`）
- 对话框主体，包含明确标题、简明后果说明与可选表单区域
- 底部操作栏，清晰区分散失／取消操作与主按钮或危险确认按钮

## 状态矩阵

| 状态 | 必须满足 |
| --- | --- |
| 关闭态 | 背景层不可聚焦或未挂载（关闭态 `<dialog>`）；触发按钮保持原有位置 |
| 常规确认打开 | 居于 `--xu-overlay` 遮罩之上，开启后焦点自动落入对话框内部 |
| 危险删除确认 | 确认按钮使用 `danger` 变体与具体动词文案（如“撤销密钥”而非笼统“确定”） |
| 表单 / 校验打开 | 输入校验失败时原位展示错误信息，不意外关闭浮层 |
| 取消 / 确认关闭 | 点击取消、`Escape` 键或确认动作后关闭，并将焦点精确归还给原触发控件 |
| 移动端视口 | 收窄为紧凑卡片或底部弹出样式，按钮保持不少于 `44 px`（原生 `48 dp`）可触区域 |

## 键盘行为

- 打开对话框时自动将焦点移入首个可交互元素或安全取消按钮。
- 开启期间 `Tab` / `Shift+Tab` 仅在对话框内部循环，不穿透至底层页面。
- 按下 `Escape` 关闭对话框（阻塞任务除外），并将焦点恢复到打开弹窗前的触发按钮。

## Token 与尺寸

浮层表面使用 `--xu-surface`、`--xu-border`、`--xu-radius-lg`（桌面 `12 px` / 移动端 `phone_dialog_radius` `16 dp`），遮罩采用 `--xu-overlay`（对应原生 `xuui_tokens.overlay(dark)`）。桌面端底部按钮右对齐，窄屏下充分拉伸或纵向排布。

## 原生映射

对应 `widgets.Modal` / `widgets.modal_dialog`（使用 `xuui_tokens.overlay(dark)`）与 `#ui/phone` 的 `phone.confirm_dialog`。

## 验收

- 展厅中可真实触发常规确认与危险删除两类对话框并分别执行确认与取消流程。
- 按 `Escape`、取消或确认关闭后，焦点必须稳定返回触发按钮并更新结果摘要。
- 在 `320 px` 视口下弹窗操作按钮完整可达，不出现裁切或页面横向滚动条。
- 浏览器回归测试覆盖对话框语义、Escape 关闭、焦点恢复及双主题 WCAG 2.2 AA 零违规。
