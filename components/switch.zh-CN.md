# 开关 Switch

即时生效的二元状态切换控件，明确表达开启／关闭状态与禁用前提条件。以下为组件设计与交互契约；展厅中的浏览器实现与原生边界分别说明。

## 结构

- 可见设置标签
- 胶囊轨道与滑块圆钮（`role="switch"`）
- 可选说明文字与即时状态播报区

## 状态矩阵

| 状态 | 必须满足 |
| --- | --- |
| 关闭态 | 抬升底色配清晰控件边框，`aria-checked="false"` |
| 开启态 | 品牌主色填充轨道并搭配高对比滑块，`aria-checked="true"` |
| 悬停 / 按下 | 提供边框或轨道色彩反馈，不引起布局抖动 |
| 聚焦态 | 围绕胶囊轨道显示 2 px 焦点外框 |
| 禁用态 | 原生 `disabled` 并说明前提原因，忽略切换输入 |
| 减少动效 | 跟随系统偏好直接切换位置，不强制滑动动画 |

## 键盘行为

- Tab / Shift+Tab 直接聚焦至开关控件。
- 空格（Space）或回车（Enter）立即切换状态并更新实时播报。
- 需随表单统一提交的选项仍使用复选框；仅即时生效的设置项使用开关。

## Token 与尺寸

使用 `--xu-brand`、`--xu-brand-hover`、`--xu-on-brand`、`--xu-elevated`、`--xu-control-border` 与 `--xu-focus`。桌面与 Web 整行触发高度不少于 `44 px`（`--xu-target-min`），移动端 `#ui/phone` 行高不少于 `48 dp`。

## 原生映射

对应 `widgets.Switch` / `widgets.switch_control` 与 `#ui/phone` 的 `phone.toggle_switch`；滑块过渡遵循系统减少动态效果设置。

## 验收

- 可在示例中同时操作与对比默认开启、关闭、即时反馈与禁用说明状态。
- `320 px` 视口下无页面级横向溢出，长设置标签可自然折行而不挤压胶囊轨道。
- 采用原生 `role="switch"` 与 `label` 显式关联，不依赖单一颜色区分子状态。
- 浏览器回归覆盖点击／键盘切换、实时状态反馈及双主题 WCAG 2.2 AA 零违规。
