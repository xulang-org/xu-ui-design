# 滑块 Slider

有界的数值调节控件，支持固定步长、触控友好热区与明确的数值实时读数。以下为组件设计与交互契约；展厅中的浏览器实现与原生边界分别说明。

## 结构

- 可见标签与格式化实时数值读数
- 有界范围滑轨（`min` / `max` / `step` 与 `aria-valuetext`）
- 步进微调辅助按钮及禁用对照示例

## 状态矩阵

| 状态 | 必须满足 |
| --- | --- |
| 默认态 | 轨道、高亮填充段与数值读数严格同步 |
| 聚焦态 | 控件外周呈现清晰 2 px 焦点轮廓 |
| 调节态 | 拖动或键盘步进时数值平稳变化，不引起排版跳动 |
| 边界夹紧态 | 到达最小值或最大值时稳健停止，不循环绕回 |
| 禁用态 | 原生 `disabled` 降灰展现并保留说明，不响应拖拽与键盘输入 |

## 键盘行为

- Tab 聚焦滑块；左／下方向键递减一个步长，右／上方向键递增一个步长。
- PageUp / PageDown 执行大跨度步进；Home / End 直接跳转至最小值与最大值。
- 配套的步进按钮便于触屏用户单点精确调节。

## Token 与尺寸

使用 `--xu-brand`、`--xu-elevated`、`--xu-control-border`、`--xu-focus`、`--xu-text` 与 `--xu-muted`。滑块组件在垂直方向保留不少于 `44 px`（`--xu-target-min`）的可点击与可触控高度。

## 原生映射

对应 `widgets.Slider` / `widgets.RangeSlider` 与 `#ui/phone` 的 `phone.slider`。

## 验收

- 可在示例中完成拖动、键盘方向键／Home／End 调节、步进按钮微调并查看禁用态对照。
- `320 px` 视口下轨道与读数标签对齐清晰，零横向溢出。
- 读数以明确单位和文字同步表达，不依赖滑块位置单向猜测。
- 浏览器回归覆盖键盘调节、辅助按钮与双主题 WCAG 2.2 AA 零违规。
