# 徽标与状态点 Badge

紧凑的分类、计数或实时状态标记，可与文案同行内联，也可依附于按钮、导航或列表项右上角。以下为组件设计与交互契约；展厅中的浏览器实现与原生边界分别说明。

## 结构

- 简短状态标签或数字计数（超出上限显示 `99+`）
- 可选前置状态圆点或 16 px 小图标
- 语义清晰的柔和底色或实心底色组合（`neutral`、`brand`、`success`、`warning`、`danger`、`info`）
- 当作为计数或红点角标依附时所需的宿主按钮、页签或列表项

## 状态矩阵

| 状态 | 必须满足 |
| --- | --- |
| 中性 / 品牌 | 采用浅底或朱砂主色弱对比方案，视觉上明显区别于可点击按钮 |
| 语义状态色 | 成功、警告、危险与信息四类柔和底色上的文字对比度均不少于 `4.5:1` |
| 计数角标 | 高对比实心胶囊（`--xu-brand` 底配 `--xu-on-brand` 字），超过 `99` 统一截断为 `99+` |
| 状态红点 | 紧凑未读提示点，宿主控件的无障碍名称必须包含未读状态或数量语义 |
| 窄屏换行 | 在 `320 px` 下与长标题同行折行，不挤压或裁切相邻控件 |

## 键盘行为

- 纯展示型内联徽标不进入 Tab 焦点流，避免打断键盘浏览节奏。
- 携带数字角标或状态红点的按钮／页签保持单一 Tab 停靠点，并将角标计数同步纳入宿主无障碍名称。
- 若作为可点击筛选条件存在，必须使用原生 `<button>` 而非给 `<span>` 绑定点击事件。

## Token 与尺寸

内联语义徽标使用 `--xu-subtle`、`--xu-brand-soft`、`--xu-success-soft`、`--xu-warning-soft`、`--xu-danger-soft`、`--xu-info-soft`，搭配对应深／亮色文本与边框；实心计数角标使用 `--xu-brand` 填充与 `--xu-on-brand` 文字。

## 原生映射

对应 `widgets.Badge` / `widgets.badge_attachment`（`badge_variant`、`BADGE_STATUS`、`BADGE_COUNT`、`BADGE_DOT`、`badge_solid_color`）与 `#ui/phone` 的 `phone.badge`。

## 验收

- 展厅中可同时检查全部 6 种语义色调与状态标签／数字角标／未读圆点 3 种附着形态。
- 计数交互控件可真实调节 `0`、常规计数与 `99+` 上限溢出表现。
- 全部徽标文字与底色组合在 Obsidian 深色与 Paper 浅色主题下均通过 WCAG 2.2 AA `4.5:1` 对比度门禁。
- 不允许出现脱离宿主标签或无障碍说明的孤立色点。
