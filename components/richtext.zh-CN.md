# 富文本编辑器

格式化文本编辑、样式工具栏、行内标记、段落块与辅助技术语义。以下是组件的设计与交互契约，Web 参考实现与原生能力边界分别说明。

## 结构

- 带有无障碍动作按钮的格式化工具栏
- 具备块级段落与行内运行片段语义的编辑画布
- 字符数与选区状态提示区域
- 链接与属性配置弹出层

## 状态矩阵

| 状态 | 必须满足 |
| --- | --- |
| 空白 | 显示占位提示，具备 role="textbox" 与 aria-multiline="true" |
| 聚焦 | 当前运行片段边界光标清晰可见，工具栏高亮激活样式 |
| 选区范围 | 选区整洁跨越多个运行片段；格式操作统一应用至相交片段 |
| IME 输入法组合中 | 预编辑组合文字带平台下划线显示；格式操作挂起直到提交 |
| 只读 | 格式工具栏隐藏或禁用；内容支持选择与复制 |
| 禁用 | 原生 disabled；内容不可编辑与聚焦 |

## 键盘行为

| 快捷键 | 动作 |
| --- | --- |
| Ctrl+B / Cmd+B | 切换选中文字或当前插入点的粗体样式 |
| Ctrl+I / Cmd+I | 切换选中文字或当前插入点的斜体样式 |
| Ctrl+U / Cmd+U | 切换选中文字或当前插入点的下划线样式 |
| Ctrl+K / Cmd+K | 为选中文字打开超链接编辑弹层 |
| Shift+Enter | 在当前段落内插入软换行 |
| Enter | 切分块并在继承样式下新建段落 |
| Tab / Shift+Tab | 列表项块增加或减少缩进，或在根层级移出焦点 |

## Token 与尺寸

使用 --xu-text、--xu-muted、--xu-brand、--xu-focus、--xu-control-border 和 --xu-surface。编辑器最小高度 160 px；工具栏按钮保持至少 44 px 触控区域。组件必须适配暗色和亮色，并尊重用户根字号与减少动效偏好。

## 原生映射

widgets.RichEditor / widgets.rich_editor；原生 IME 代理与 DirectWrite / CoreText 多运行片段文本排版，并桥接平台 UIA / NSAccessibility 文本模式接口。

## 验收

- 默认、聚焦、格式化选区、只读和禁用状态均可在对应效果中操作或对照。
- CJK IME 组合输入准确在光标处定位候选框，且不破坏现有格式片段。
- 320 px 下没有页面级横向溢出，工具栏自适应换行且不裁剪操作按钮。
- ARIA 关系关联工具栏与编辑画布；屏幕阅读器在格式切换时播报状态变更。
- 浏览器回归覆盖行内样式、块切分与 IME 提交路径；屏幕阅读器语音真实验收另行记录，不以自动扫描代替。
